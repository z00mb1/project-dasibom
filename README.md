# 다시봄

실종 예방부터 신고·제보, 위치 확인, 발견 지원까지 하나의 흐름으로 연결하는 통합 실종 대응 서비스입니다.

## 프로젝트 소개

다시봄은 보호자, 시민, 관리자, 피보호자가 하나의 서비스 안에서 연결되어
실종 예방부터 발생 이후 신고·제보 및 위치 기반 발견 지원까지 이어질 수 있도록 개발한 졸업작품입니다.

모바일 애플리케이션, 키오스크, NFC 키링, GPS 위치 정보, AI 연령 변화 이미지 생성 기능을 연동하여
실종 상황에서 필요한 여러 기능을 통합적으로 제공하는 것을 목표로 합니다.

## 주요 기능

- 사용자 로그인 및 권한별 화면 제공
- 실종자 목록 및 상세 정보 조회
- 실종 신고 및 시민 제보 등록
- 신고·제보 처리 상태 확인
- 사전 예방 등록 및 피보호자 관리
- 보호자 전용 실시간 위치 확인
- 생활안전지도 조회
- AI 기반 연령 변화 이미지 생성
- 키오스크 실종자 정보 조회
- NFC 키링을 이용한 긴급신고 및 위치 확인
- 관리자 신고·제보 확인 및 처리

## 시스템 구성

- Mobile App
  - 실종자 조회
  - 신고 및 제보
  - 사전 예방 등록
  - 보호자 위치 관리
  - AI 몽타주 확인

- Kiosk
  - 실종자 정보 조회
  - 생활안전시설 조회
  - NFC 인식
  - 긴급신고

- Backend
  - 사용자 및 권한 관리
  - 신고·제보 데이터 처리
  - 예방 등록 관리
  - 위치 및 알림 데이터 처리
  - AI 서버 연동

- AI
  - 입력 얼굴 이미지를 기반으로 목표 연령을 반영한 얼굴 이미지 생성

- Hardware
  - GPS 기반 위치 정보 수집
  - NFC 키링 연동
