# 다시봄 Front-end

실종 예방부터 신고·제보, 위치 확인까지 지원하는 통합 실종 대응 서비스 **다시봄**의 모바일 애플리케이션 프론트엔드입니다.

## 담당
- 박주원
- Front-end

## 주요 기능
- 사용자 로그인 및 회원가입
- 실종자 목록 및 상세 정보 조회
- 실종 신고 및 시민 제보 등록
- 신고·제보 처리 상태 확인
- 사전 예방 등록 및 피보호자 관리
- 보호자 전용 실시간 위치 확인
- 생활안전지도 조회
- AI 몽타주 생성 및 결과 확인
- 긴급신고 WebSocket 알림
- 권한별 화면 및 기능 분기

## 기술 스택
- Flutter
- Dart
- Firebase
- Kakao SDK
- REST API
- WebSocket
